    Pertinent equations

    Distances in meters inside each equation; vergence and power in diopters

    Single refracting surface

    F = (n2 − n1) / r
    F = n2 / f2 = −n1 / f1

    Each face of the lens is one surface. For the front, n1 = no and n2 = n. For the back, n1 = n and n2 = ni.

    Vergence

    L1 = n1 / l1   L2 = n2 / l2
    L2 = L1 + F   m = L1 / L2 = n1l2 / n2l1

    Light travels left to right. A real object has a negative distance and negative vergence; a real image has a positive distance.

    Reduced thickness and equivalent power

    d̂ = d / n
    Fe = F1 + F2 − d̂ F1F2

    Fe is one imaginary power that does all the refracting at two planes, H1 and H2. The nominal power F1 + F2 is the thin-lens shortcut, and it fails when d̂F1F2 is not small.

    Back vertex power

    Fv = F1 / (1 − d̂F1) + F2 = Fe / (1 − d̂F1)
    fv = ni / Fv  (from A2 to f2)

    The vergence leaving the back surface when plane waves enter the front. This is the power written on a spectacle prescription.

    Front vertex (neutralizing) power

    Fn = F2 / (1 − d̂F2) + F1 = Fe / (1 − d̂F2)
    fn = −no / Fn  (from A1 to f1)

    The vergence that must arrive at the front surface for plane waves to leave the back: the same formula with F1 and F2 swapped.

    Equivalent focal lengths and principal planes

    f1 = −no / Fe   f2 = ni / Fe  (from H1, H2)
    A1H1 = fn − f1   A2H2 = fv − f2

    Vertex focal lengths are measured from the lens surfaces; equivalent focal lengths are measured from the principal planes. Their difference places each plane.

    Imaging with the equivalent system

    L1,H1 = no / l1,H1   L2,H2 = ni / l2,H2
    L2,H2 = L1,H1 + Fe   mt = L1,H1 / L2,H2

    Measure the object from H1 and the image from H2, then use the ordinary vergence equation with Fe.

    Nodal points

    H1N1 = H2N2 = f1 + f2 = (ni − no) / Fe

    A ray aimed at N1 leaves from N2 at the same angle. The nodal points sit on the principal planes only when no = ni.

    Vergence effectivity

    V2 = V1 / (1 − dV1)   V1 = V2 / (1 + dV2)

    How vergence changes as light travels a distance d (in meters, reduced by the index inside a medium). The back and front vertex power formulas are this step applied inside the lens.

    Things to remember

    • Principal planes are planes of unit magnification. An object at H1 images at H2 with m = +1, and a ray reaching H1 at some height leaves H2 at that same height.
    • Symmetry points. An object at 2f1 (from H1) images at 2f2 (from H2), even when no ≠ ni.
    • The cardinal points (focal, principal, nodal and symmetry points) are fixed properties of the lens. They do not move with the object.
    • The principal planes can sit outside the lens and can cross, as in strongly bent menisci and the two-surface example below.
    • Sign check from the lecture: Keating equations 15.7 and 15.8 are missing minus signs. Use Fe = −no/f1 and Fn = −no/ff.
