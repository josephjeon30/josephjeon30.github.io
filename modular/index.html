Modular arithmetic

Interactive notes on the way to RSA: clock arithmetic, Euclid's algorithm, and modular inverses.

1. Congruence · 2. GCD and Euclid · 3. Modular inverses

1. Congruence and clock arithmetic

a ≡ b (mod n) means n divides a − b. Every integer has exactly one representative in {0, 1, …, n−1}: write a = qn + r with 0 ≤ r < n. Congruence respects + and ×, so you can reduce mod n at any step of a calculation. Example: 2³ = 8 ≡ 1 (mod 7), so 2¹⁰⁰ = (2³)³³·2 ≡ 2.

Careful with negatives: −7 mod 5 is 3, since −7 = (−2)·5 + 3. JavaScript's -7 % 5 gives −2.

2. GCD and the Euclidean algorithm

Key lemma: gcd(a, b) = gcd(b, a mod b). If a = qb + r, any common divisor of a and b also divides r = a − qb, and any common divisor of b and r divides a. Repeat until the remainder is 0; the last nonzero remainder is the gcd. The remainders at least halve every two steps, so this is fast even on huge numbers.

Geometrically: tile an a×b rectangle with the largest squares that fit, then repeat on the leftover strip. The last square's side is the gcd.

Try consecutive Fibonacci numbers (89, 55) for the worst case, or 96 and 24 for a one-step finish.

3. Bézout and modular inverses

Bézout's identity: there are integers s, t with a·s + n·t = gcd(a, n). If gcd(a, n) = 1, reducing mod n kills the n·t term, so a·s ≡ 1 and s is the inverse a⁻¹. If gcd(a, n) = d > 1, then d divides every a·x − (multiple of n), so a·x ≡ 1 is impossible. Hence a⁻¹ mod n exists exactly when gcd(a, n) = 1.

Extended Euclid tracks the coefficients as it goes: every row keeps r = a·s + n·t, and each new row is the row two above minus q times the row above. In RSA, the private key is d = e⁻¹ mod φ(n), computed exactly this way.
